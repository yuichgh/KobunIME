# 0.1.11／0.1.13／0.1.14／0.1.15 線形rerankerの出典と再配布

`reranker.json` は20個の数値特徴に対する二組の重みと汎用的な適用閾値だけです。第1段は0.1.10までの重みを保持し、第2段だけを追加学習しました。教師となる語の並びは、[校異源氏物語テキストDBのTEI本文](https://github.com/kouigenjimonogatari/kouigenjimonogatari.github.io/tree/master/xml/master)から採りました。取得版は commit `89a60fe7b18c1eebb91f160c068b31e857776022`。同リポジトリの説明と、使用した各 `xml/master/*.xml` の `<availability>` は本文データを [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) と表示しています。`Tools/prepare_verified_reranker_data.py` は読み込むファイルごとにこの表示を確認し、無い場合は停止します。

読みの作成には [OpenCHJ-Genji](https://github.com/togiso/OpenCHJ-Genji) commit `4a85a539934bad6b938322ad9bbb169daa7625c6` の形態論情報（小木曽智信、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）を使います。書字形ごとに孤立した読みだけを集計し、複数の読みが残る語を捨てます。OpenCHJ側の本文順、位置、文境界、連続トークンは教師の語順に使いません。元の本文は別の権利条件であるため、この区別を維持しています。

候補の数値特徴には中古和文UniDic 2025.12 の加工辞書を使います。辞書・接続行列の出典は従来どおり国立国語研究所「通時コーパス」プロジェクト／小木曽智信、[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) です。これらから学習した `reranker.json` は、保守的に **CC BY-NC-SA 4.0** で配布し、帰属・非営利・継承条件を維持します。アプリのMITコード、各辞書、各N-gramは従来どおり別ファイル・別ライセンスです。

旧文字N-gramの[土佐日記・方丈記・徒然草などのCC BY-SA 4.0本文](Corpus-LICENSE.md)は、**このrerankerの教師データにもゲート調整にも使いません**。0.1.8の文字N-gramモデルは従来どおり独立した数値特徴として読み込むだけで、この重みファイルに本文・N-gram表・語順・文境界を複製しません。ShareAlikeの異なるライセンスを一つの教師コーパスに混ぜることを避けています。[Creative Commonsの互換ライセンス一覧](https://creativecommons.org/compatible-licenses/)も確認しました。

改変内容：OpenCHJの形態論行を孤立した書字形・読み対応へ集約し、CC0 TEIから抽出・正規化した本文だけをその対応で分割。辞書上でも曖昧な読み、分割不能な範囲、候補に正解がない例は学習から除外します。巻02〜36を学習、37〜43を調整、44〜54を最終評価に分け、巻01と実機8例は学習から除外しました。0.1.10の順位を第1段に残し、調整集合で既存Top-1を壊さず10件以上改善する候補から、既存Top-5・0.75以上の信頼度・1000点以内のスコア差を持つ第2段を選びました。実行時には本文・例文対・候補対を同梱せず、約2.2 KBの重みファイルだけを参照します。固有の入力文字列、正解表記、作品IDは特徴量にありません。

学習手順は `Tools/prepare_verified_reranker_data.py` → `Tests/reranker_dump.swift` → `Tools/train_reranker.py` → `Tools/select_cascade_reranker.py`。固定200語形は以前から短語の適用閾値に使われているため、未使用最終評価とは呼びません。別作品558件と巻44〜54の保留集合を別に示します。詳細は `../EVALUATION-0.1.11.md` を参照してください。

0.1.13の `lattice-reranker.json` も同じ出典、データ分離、20個の数値特徴、**CC BY-NC-SA 4.0** を維持します。変更点は、N-gramをbeam探索中に使った新しい候補分布に対して巻02〜36の8,000件で重みを再学習し、巻37〜43の1,800件で適用条件を選び直したことです。既存rerankerを先に適用し、信頼度2.0以上・旧総合スコア差6000点以内の長い入力だけを追加モデルで再評価します。巻44〜54の3,000件、別作品558件、固定200件、実機8例、別の保留2,000件×2は重み学習に含めません。再現手順は `Tests/reranker_dump.swift` → `Tools/train_reranker.py` → `Tools/select_lattice_reranker.py` です。本文、教師例、候補対は同梱せず、約1.1 KBの重みだけを配布します。詳細は `../EVALUATION-0.1.13.md` を参照してください。

0.1.14は0.1.13の重みを `incumbent-reranker.json` としてそのまま保持し、新しい候補分布用の `lattice-reranker.json` だけを再学習しました。学習8,000件・調整1,800件と除外集合は0.1.13と同じです。pairwise logistic、hinge型と特徴集合を比較し、文字種比率、左文脈差、疎文字、追加辞書・複合語・未知語の個数に対応する重みを0にした構造的特徴集合を採用しました。実行時は0.1.13互換経路の1位を先頭に置き、長い入力の上位10候補、信頼度2.0以上、旧総合スコア差6000点以内だけを新モデルで再順位付けします。巻44〜54の3,000件、別作品558件、固定200件、実機8例、追加保留2,000件×2は学習・閾値選択に使っていません。本文、教師例、候補対は同梱せず、数値重み2ファイルだけを配布します。詳細は `../EVALUATION-0.1.14.md` を参照してください。

0.1.15では補助辞書由来の観測強度を数える21番目の特徴を実装し、同じ学習8,000件・調整1,800件でpairwise logisticを再学習しました。しかし、既存正解を守るゲートを適用すると保留集合で安全な純改善が得られなかったため、新しい重みは採用していません。配布する3モデルは0.1.14の20特徴の重みを保持し、21番目に0を追加したものです。したがって既存候補の順位付けは0.1.14と同じで、補助辞書の候補追加と限定的な構造ゲートだけが0.1.15の変更です。再学習の比較と不採用理由は `../EVALUATION-0.1.15.md` に記録しています。
