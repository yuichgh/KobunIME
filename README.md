# 古文入力 — KobunIME

古文を歴史的仮名遣いで入力するための、Apple Silicon Mac向けの無料IMEです。
ローマ字で入力し、ライブ変換またはSpaceキーで候補を選びます。特定作品専用の入力モードではなく、古文の入力を補助することを目指しています。

**現在の配布版：0.1.16（試用版）**

## ダウンロード

このページの **Releases** を開き、`KobunIME-0.1.16-macOS-arm64.zip` をダウンロードしてください。
GitHubが自動生成する `Source code (zip)` / `Source code (tar.gz)` は紹介文・配布関連ファイルのアーカイブです。IME本体は含まれません。

ZIPを展開し、`古文入力-0.1.16をインストール.command` を開いて、表示内容を確認して進めます。
インストール後は入力ソースから「古文入力」を選びます。詳細は [インストール・更新・削除の案内](INSTALL.md) を参照してください。

## 主な機能

- 歴史的仮名遣いと文語の語形を使った変換
- ライブ変換と候補選択、文節境界の調整
- 古文の表記統計・文字／語N-gram・軽量な学習済みモデルによる候補順位付け
- このIMEで直前に確定した文字列を使った左文脈の評価
- 確定結果をMac内に保存するユーザー学習

変換処理はMac内で行います。外部API・クラウド変換・アクセス解析は使いません。詳しくは [プライバシー説明](PRIVACY.md) を参照してください。

## 対応環境

- Apple Silicon搭載Mac（arm64）。Intel Mac、iPhoneには非対応です。
- ビルド上の最低OSはmacOS 13です。実機確認環境はM1 Pro・macOS 26・Safariです。
- その他のOSバージョン・アプリとの互換性は十分に確認できていません。

## 署名・公証について

この版は **Developer ID署名・Appleの公証を受けていません**。アプリにはローカルのad-hoc署名がありますが、開発元をAppleが確認した署名ではありません。macOSがインストーラや補助プログラムを止める場合があります。

公開用インストーラは、説明を表示して利用者が続行を選んだ後、コピーするアプリに付いた隔離属性などを除去します。Mac全体のGatekeeper設定は変更しません。この処理の範囲と、警告時の対処は [INSTALL.md](INSTALL.md) に記載しています。

## 開発状況

試用版です。文脈に合わない漢字が選ばれたり、期待する表記が候補にない場合があります。現代文を入力するときはMac標準の日本語入力との切り替えをお勧めします。

0.1.16は変換処理の速度改善を行った版です。特定の評価集合で0.1.15と表示結果が一致することを確認しましたが、あらゆる入力・環境で退行しないことを保証するものではありません。既知の回帰テスト失敗2件も残っています。[既知の問題](KNOWN-ISSUES.md)、[0.1.16の評価概要](EVALUATION-0.1.16.md) を参照してください。
